1"""Caja negra del cluster: registrador de datos de tamano fijo con acceso directo (Etapa 20). 

2 

3Guarda los ultimos 60 s del vehiculo (10 muestras por segundo) en datos/caja_negra.bin. 

4 

5Formato binario (little endian; ver docs/caja_negra.md): 

6- Cabecera de 64 bytes: firma "F40CNEG1", version, tamano de registro, capacidad, total de 

7 registros escritos, fecha de creacion y CRC-16. 

8- 600 registros de 32 bytes: fecha en ms, secuencia, velocidad, rpm, presiones, temperatura, 

9 combustible, voltaje, testigos (bits), causa de proteccion, estado (bits) y CRC-16. 

10El archivo se crea de su tamano final (64 + 600 x 32 = 19 264 bytes) y nunca crece: es un 

11anillo. El registro numero k va en la posicion 64 + (k mod 600) x 32 y se escribe con 

12pwrite en ese desplazamiento (acceso directo); para leer los ultimos N no se recorre el 

13archivo: se calcula donde estan. 

14 

15Politica de escritura: la interfaz solo empaqueta la muestra y la deja en una cola acotada 

16(nunca espera al disco; si la cola se llena, la muestra se descarta y se cuenta; los eventos 

17van en una lista aparte y nunca se pierden). Un hilo 

18escritor la graba y hace fsync una vez por segundo: se pierde a lo mas el ultimo segundo si 

19se va la luz, a cambio de no sincronizar 10 veces por segundo. Cada registro lleva su CRC: 

20uno danado se detecta y se salta. 

21 

22Evento: cuando se enciende un testigo critico (9, 10, 15, 16 o la puerta en movimiento) la 

23caja negra sincroniza y exporta a CSV los 10 s anteriores en logs/caja_negra/ (se conservan 

24los 20 mas recientes)."""

80def empaquetar(valores, secuencia): 

81 """Diccionario -> 32 bytes. Escalas: decimas de km/h y de C, centesimas de bar, decimas de V.""" 

82 causa = valores["causa"] 

83 estado = sum(1 << i for i, nombre in enumerate(ESTADOS) if valores[nombre]) 

84 cuerpo = REGISTRO.pack( 

85 valores["fecha"], secuencia & 0xFFFFFFFF, 

86 _entero(valores["velocidad_kmh"], 10, 0, 3600), _entero(valores["rpm"], 1, 0, 9000), 

87 _entero(valores["presion_aceite_bar"], 100, 0, 1000), _entero(valores["temp_agua_c"], 10, -400, 1500), 

88 _entero(valores["presion_turbo_bar"], 100, 0, 200), 

89 SIN_DATO if valores["combustible_pct"] is None else _entero(valores["combustible_pct"], 1, 0, 100), 

90 SIN_DATO if valores["voltaje_v"] is None else _entero(valores["voltaje_v"], 10, 0, 200), 

91 valores["testigos"], SIN_DATO if causa is None else CAUSAS_MOTOR.index(causa), estado, 0) 

92 return cuerpo[:-2] + struct.pack("<H", _crc(cuerpo[:-2]))

95def desempaquetar(datos): 

96 """32 bytes -> diccionario; ValueError si el CRC no coincide (registro danado).""" 

97 campos = REGISTRO.unpack(datos) 

98 if _crc(datos[:-2]) != campos[-1]: 

99 raise ValueError("crc invalido") 

100 fecha, secuencia, vel, rpm, aceite, agua, turbo, comb, volt, testigos, causa, estado, _ = campos 

101 return { 

102 "fecha": fecha, "secuencia": secuencia, "velocidad_kmh": vel / 10, "rpm": rpm, 

103 "presion_aceite_bar": aceite / 100, "temp_agua_c": agua / 10, "presion_turbo_bar": turbo / 100, 

104 "combustible_pct": None if comb == SIN_DATO else comb, "voltaje_v": None if volt == SIN_DATO else volt / 10, 

105 "testigos": [n for i, n in enumerate(TESTIGOS) if testigos >> i & 1], 

106 "causa": None if causa == SIN_DATO else CAUSAS_MOTOR[causa], 

107 **{nombre: bool(estado >> i & 1) for i, nombre in enumerate(ESTADOS)}, 

108 }
